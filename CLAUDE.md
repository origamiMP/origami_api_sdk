# Instructions for Claude

This project is the PHP SDK of the central Origami API (`origami-mp/origami-api-sdk`), used by origami_admin_v2 among others.

Before writing, modifying or reviewing code in this project (repositories, param bags, DTOs, traits, contracts, exceptions, enums, helpers, tests, Pint or PHPStan configuration) — including for a task that looks trivial — systematically invoke the `sdk-conventions` skill through the Skill tool. That skill is what documents the code, file-organization and test conventions of this project.
